## What it does

`main.py` writes one original, single-line roast of my own AI agent to `/output/entry.txt`:

> My agent's plan for every task is flawless: spawn three subagents, write a tracker, then ask me what the task was.

Inside the 1–200 character gate. Funny, playful, never hateful — and it dodges the stock hallucination/apology jokes for a fresher angle: the agent that plans the work to death, then forgets what the work was.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python stdlib, no dependencies, deterministic — two runs produce byte-identical output.
